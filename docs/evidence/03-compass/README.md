# 03 - Babelfish Compass and SQL Server Validation Evidence

## Objective

This folder contains evidence related to the SQL Server source environment validation and the preparation phase for the Babelfish Compass assessment.

The goal of this step is to document the source database readiness before continuing with compatibility analysis, migration planning and PostgreSQL/Babelfish validation.

| File | Description |

## Technical Context

This phase validates the SQL Server source environment before migration execution.

The validation confirms:

- Local lab environment readiness.
- Docker container availability.
- SQL Server availability.
- SQL Server version.
- AdventureWorksLT2019 database status.
- Initial readiness for Babelfish Compass compatibility assessment.

## Portfolio Relevance

This evidence demonstrates a structured migration approach with traceability, technical validation and documentation discipline.

It supports the migration journey from SQL Server to PostgreSQL using Babelfish compatibility by proving that the source environment was validated before the migration and assessment phases.
